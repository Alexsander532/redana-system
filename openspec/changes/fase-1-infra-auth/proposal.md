# Fase 1 — Infra + Auth + Shell

## Why
A infraestrutura de auth e o shell do dashboard são pré-requisitos para todas as features seguintes. Sem auth, não há como associar redações a usuários.

## What Changes
- Implementa cadastro e login de usuarios com Supabase Auth
- Adiciona protecao de rotas no frontend e autorizacao na API
